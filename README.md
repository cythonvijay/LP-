**Website concept & implementation:** Vijay Pandiselvam (© 2026). The creator credit is included discreetly in the website footer and source files. RoseDsigns names, trademarks, brand identity and any supplied brand assets remain the property of their respective owners. Third-party photography is loaded from Unsplash and should be checked for licensing/usage suitability before production.

A responsive, editorial-style landing page built with semantic HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or run a local static server from this folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Files

- `index.html` — page structure and content
- `styles.css` — design system, responsive layouts and motion
- `script.js` — mobile navigation, reveal effects, form validation and email handoff

## Before publishing

1. Confirm all agency copy, service names and contact details with RoseDsigns.
2. Replace the self-initiated portfolio concepts and imagery with approved agency work if available. The current project names are explicitly presented as concept studies.
3. The contact form validates fields and opens the visitor's configured email application addressed to `hello@rosedsigns.com`. Confirm that this is the correct public enquiry address. For submissions without an email client, connect a form backend such as Formspree, Netlify Forms or a custom API.
4. Replace external image URLs with optimized, licensed assets owned or approved for the site before production.
5. Test keyboard navigation, mobile layouts, links and image loading on target browsers.

## Deployment

This is a static site and can be deployed to Netlify, Vercel or GitHub Pages. Upload the contents of this folder or connect the repository; no build command is required.
